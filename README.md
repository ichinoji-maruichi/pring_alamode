# ぷりんあらも〜ど - 流体シミュレーター

古のフリーソフト（XX-CAKE、たろたろそ〜す等）の系譜を汲む、ブラウザで動く画像揺らし＆流体シミュレーター。
単一HTMLファイルで完結・依存ゼロ（AI機能のみCDN）・GitHub Pagesにそのまま置ける。

## 使い方

`index.html` をブラウザで開くだけ。サーバー不要（PWA・AI機能はhttp(s)配信時のみ有効）。

画像の読み込み: 左上のボタン / プレビューへのドラッグ&ドロップ / Ctrl+V貼り付け。**新規読み込み時はAIが自動で揺れる範囲を選び、数秒で「ゆらす」に入る**（AIが失敗・遅い時は全面フェザーマスクで即揺らせる。範囲を絞るのは「ゆれ設定」で。インポート時は発動しない）。

### 3つのモード（右カラムのタブ）

- **ゆらす**: タップで押し込み→離すとバウンド。全体をゆらす（縦/横ビクン）、自動ゆれ（方向・強度・速さ）、加速度センサー、静止
- **ゆれ設定**: レイヤーごとに物理（やわらかさ/伝播/おさまり/ふり幅）を設定。範囲を塗る／消す（筆サイズ・硬さ）／AI選択（追加モード既定ON）。揺れプレビューボタンは押している間だけ揺らす。各スライダーは右の数値ボックスで直打ち・↑↓・ホバーホイール（Shiftで10刻み）でも調整可。PCショートカット: **B**=塗る / **E**=消す / **X**=切替
- **かける**: 液体（いろ/濃さ/とろみ/垂れ強度/大きさ）をかけて垂らす。傾きセンサーで流れる向きが変わる（左右の符号は自動補正）

### そのほか

- **フル画面で遊ぶ**: プレビューを画面いっぱいに拡大。ピンチ/ホイールでズーム、2本指でパン。スマホの画面録画と好相性
- **録画**: 左の「● 録画」。長さ3/5/10秒・カウントダウン・端クロップ・透かしは「録画設定」。MP4対応環境はMP4、非対応はWebM。Web Share API対応
- **効果音**: Web Audio による全合成SE（音源ファイルなし・依存ゼロ）。押し込み「むにゅ」／ボヨン（強さでピッチ・音量が変化）／液体「ぱしゃ」＆注ぎ音／シェイク声（センサー・パッドの激しさに追従）。「その他」で効果音トグル（既定ON）と音量（既定50%）を設定、選択は保存。録画にも音声トラックを合成（対応環境）。自動ゆれ・UIクリック・カウントダウンには音を付けない。※iPhoneのマナーモード中はWeb Audioが無音（本体仕様）
- **振動**: 揺れが大きい瞬間にハプティック（対応端末・既定OFF）
- **ヘルプ**: タイトルバー右の「?」（初回のみハイライト）。ドラッグで移動可。物理項目の説明は「選択中レイヤーの物理」右の「?」から
- **言語**: 左カラムの Language プルダウンで 日本語 / English / 繁體中文 / 简体中文 / 한국어 を切替（リロード不要・選択は保存）。URLに `?lang=en` 等を付けると一時的にその言語で起動（共有リンク用。localStorageには保存せず、パラメータなしで再訪すると元の設定に戻る）
- **WebGL復帰**: モバイルでタブを裏に回す等でGLコンテキストが失われても、復帰時に自動で再構築（マスク・揺れは継続、乾き途中の液体のみクリア）

## レイアウト

- デスクトップ: 3カラム（左=ファイル/録画/その他、中央=プレビュー、右=モード選択+パラメータ）
- スマホ: 縦積み（上帯=ファイル/録画 → プレビュー → モード+パラメータ → その他）

## 多言語対応（i18n）

UI文言は `index.html` 冒頭の `I18N` 辞書に一元化（`ja` が原文＝正）。静的要素は `data-i18n`／`data-i18n-html`／`data-i18n-title` 属性、動的文言は `t(key, vars)` 経由。ブランド名「ぷりんあらも〜ど」・免責/著作権・保存ファイル名は全言語で翻訳しない。

**言語を追加するには:**

1. `I18N` に新しい言語ブロックを追加（`en` をコピーして各値を翻訳）
2. `#langSel` に `<option value="xx">自言語表記</option>` を1行追加
3. 以上。動作確認は devtools コンソールで `checkI18n()` を実行すると、`ja` を基準に各言語の未翻訳キー（missing）・余分なキー（extra）が一覧表示される

初回訪問時の言語自動判定: `ja`→日本語 / `ko`→韓国語 / `zh` のうち `tw`・`hk`・`mo`・`hant` を含むもの→繁体字（`zh-Hant`）・その他の `zh`→簡体字（`zh-Hans`） / それ以外→英語。選択は `localStorage`（`purin.lang`）に保存される。未翻訳キーは `現在言語 → en → ja` の順にフォールバックする。

### フォント

UIフォントは CSS 変数 `--uiFont` で言語ごとに切り替える（`applyLang()` 内の `LANG_FONT`）。各言語の標準的なシステムフォント（日本語系／`PingFang TC`・`Microsoft JhengHei`／`PingFang SC`・`Microsoft YaHei`／`Apple SD Gothic Neo`・`Malgun Gothic` 等）を使い、Webフォントは同梱・依存しない。中国語で日本語字形が混ざらないよう、繁体／簡体はそれぞれの地域フォントを先頭に置く。`<html lang>` も言語ごとに設定する。

## リリース手順

**リリースのたびに `sw.js` の `CACHE` バージョン文字列を必ず bump すること**（例: `purupuru-v3.0.1` → `v3.0.2`）。`index.html` はネットワーク優先で即反映されるが、アイコン等の静的アセットはキャッシュファーストのため、bump しないと更新が古いキャッシュのまま届かない。静的アセットを差し替える場合はファイル名にバージョンを含める（例: `ogp-v2.png`。SNSのカードキャッシュ対策にもなる）。

## プライバシー

画像・録画はすべて端末内で処理され、どこにも送信されません（AIモデルのDLを除く）。

## ファイル構成

```
index.html      # 単一HTMLコア（これだけで基本機能が全部動く）
manifest.json   # PWA
sw.js           # Service Worker（オフラインキャッシュ）
icons/          # PWAアイコン
proto.html      # 検証用プロトタイプ（core v0.14、リファレンス実装）
```

## 実装メモ

- 揺れコア: WebGLバネ格子（40列グリッド、1/120秒固定サブステップ）。インタラクションは押し込み→バウンド方式
- レイヤー: 上位レイヤー優先のアルファブレンドで頂点ごとに物理を合成。色オーバーレイは選択中レイヤーのみ
- 液体: GPU濃度場＋湿り気場のピンポンバッファ（新しくかけた分だけが流れる）
- センサー符号差（iOS/Android）は `DeviceMotionEvent.requestPermission` の有無でiOSを検出して内部吸収（重力反転ボタンは廃止）
- v2.0でSPEC_2に沿ってUIを全面再構築（3モード化・3カラム・フルスクリーン・録画改善・ヘルプ）。物理/液体/AIのコアロジックはプロトタイプから流用
